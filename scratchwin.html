FAQ

How does it work?

You add one line of code to your Shopify theme. It turns a standard Klaviyo full-screen pop-up into an interactive Scratch & Win experience — everything else (targeting, rewards, email capture, flows) is configured in Klaviyo, the way you already know.

Do I need a developer?

No. If you can paste a snippet into your Shopify theme, you can install it. The step-by-step guide walks you through it in under 10 minutes.

Do I still get all my Klaviyo analytics?

Yes. It's a native Klaviyo pop-up, so submissions, conversion rates, and every metric you already track stay exactly where they are.

Does the code collect any customer data?

No. The script only handles the Scratch & Win interaction on your visitor's screen — no tracking, no analytics, no data sent to third parties. Every submission goes straight to Klaviyo, exactly like a standard pop-up. GDPR-friendly by design.

Can I use one license on multiple stores?

No — each license is generated for a single store domain. If you run more than one store, you'll need one license per domain.
