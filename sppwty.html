How to Implement Scratch&Win Pop-Up

Thank you for your purchase! Here's the full guide.

Step 1: Create a new Full-Screen Form on Klaviyo

Create a form from scratch, select the "Full Screen" option, and select your email list.

Step 2: Create a blank step

Create a new blank step in your Klaviyo form and place it as the first step.

Step 3: Add an HTML element

In the blank step, add an HTML element with the following structure:

<div class="lb-scratch" role="group" aria-label="Scratch card">
    <p class="lb-scratch__prize">10% DI SCONTO</p>
</div>

Change the prize text as needed.

Step 3: Add custom CSS

In the styling panel, scroll down to the "Custom CSS" section, enable it, and add the following CSS:

form.klaviyo-form {
  --lb-bg-from: INSERT YOUR START COLOR HERE;
  --lb-bg-to: INSERT YOUR END COLOR HERE;
  --lb-price-text: INSERT YOUR PRIZE TEXT COLOR HERE;

  --lb-img-left: url('INSERT YOUR LEFT IMAGE URL HERE');
  --lb-img-left-rotation: 10deg;

  --lb-img-right: url('INSERT YOUR RIGHT IMAGE URL HERE');
  --lb-img-right-rotation: -20deg;
}

.lb-scratch {
  position: relative;
  width: 300px;
  max-width: 100%;
  height: 220px;
  margin: 0 auto;
  border-radius: 10px;
  overflow: hidden;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  gap: 8px;
  text-align: center;
  user-select: none;
  background: #fff;
  animation: lb-pop .6s cubic-bezier(.2,.7,.3,1) .4s both;
}

.lb-scratch__prize {
  color: var(--lb-price-text);
  margin: 0;
  font-family: Barlow, sans-serif;
  font-weight: 700;
  font-size: 50px;
  line-height: 1;
}

form.klaviyo-form {
  position: relative;
  isolation: isolate;
  overflow: hidden !important;
  background: linear-gradient(to top, var(--lb-bg-from) 0%, var(--lb-bg-to) 100%) !important;
}

Step 4: Customize your CSS

Adjust values in the CSS variables below following the instructions:

  • --lb-bg-from: The starting color of the gradient background
  • --lb-bg-to: The ending color of the gradient background
  • --lb-price-text: The color of the prize text
  • --lb-img-left: The URL of the left image
  • --lb-img-left-rotation: The rotation angle of the left image (in degrees)
  • --lb-img-right: The URL of the right image
  • --lb-img-right-rotation: The rotation angle of the right image (in degrees)

TIP: Upload your images in your Shopify media library and use the URLs here for better performance. Use square PNG images for best results.

Step 5: Add the right class to the claim button

Select the claim button and replace the existing class with lb-claim.

Step 6: Add the script in your Shopify store

  • Go to your Shopify admin panel
  • Navigate to "Online Store" > "Themes"
  • On the live theme, click on "Actions" > "Edit code"
  • In the left sidebar, find and click on "theme.liquid" under the "Layout" section
  • Scroll down to the closing </body> tag and paste your unique script.
